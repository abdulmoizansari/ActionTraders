# Action Traders

Frontend clone of a Pakistan industrial safety storefront (layout and catalogue structure inspired by [finemarksign.com](https://finemarksign.com/)).

Brand on this project is **Action Traders**. Product photos are icon placeholders; prices stay **Call for Price**.

## Run locally

Open `index.html` in a browser, or from this folder:

```powershell
py -m http.server 5173
```

Then visit http://localhost:5173

## Pages

- Home, shop (filters), product detail
- About, services, clients, contact
- Enquiry cart (saved in the browser)
